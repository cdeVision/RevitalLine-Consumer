# Project Overview — cdeVision 7 Block Development

Custom WordPress theme using ACF blocks. Theme code lives at the repository root.

## Theme structure

```
/                        ← theme root
├── functions.php        ← theme setup, script/style enqueue, admin tweaks
├── style.css            ← compiled front-end styles (generated by Gulp)
├── block-style.css      ← compiled editor styles (generated by Gulp)
├── header.php / footer.php / page.php / single.php / etc.
├── page-home.php        ← home page template
├── page-inc-content-start.php / page-inc-content-end.php  ← shared wrappers
├── gulpfile.js          ← Gulp build (Sass → CSS, BrowserSync)
├── blocks/
│   ├── blocks.php       ← block registration, helper functions, editor config
│   ├── _blocks.scss     ← imports all block Sass partials
│   ├── custom-admin.js  ← editor-side JS
│   └── <block-name>/   ← one folder per block
│       ├── block.json   ← ACF block definition
│       ├── <block-name>.php  ← render template
│       └── _block.scss  ← block styles
├── sass/
│   ├── style.scss       ← main front-end entry point
│   ├── block-style.scss ← editor entry point
│   ├── _variables.scss  ← colors, fonts, spacing, mixins
│   ├── _base.scss / _grid.scss / _header.scss / _footer.scss / etc.
│   └── _blocks.scss     ← (imported via blocks/_blocks.scss)
├── includes/
│   ├── functions/       ← PHP helpers (core.php, acf.php, extras.php, posts.php, etc.)
│   ├── fontawesome-6.5.2/
│   ├── slick/           ← Slick carousel
│   └── js/              ← core.js, has-animation.js
└── acf-json/            ← ACF field group JSON files (synced)
```

## Build process

- **Gulp** compiles Sass → CSS with autoprefixer.
- Entry points: `sass/style.scss` → `style.css`, `sass/block-style.scss` → `block-style.css`.
- `gulp` (default task) runs BrowserSync proxy + Sass watch + reload on PHP/JS changes.
- Proxy URL: `http://cdev6block.local/`

## ACF block pattern

### Registration
Blocks auto-register in `blocks/blocks.php` via `register_acf_blocks()`:
- `page-header` → `cdev-page-banners` category (special registration)
- `home-*` blocks → `cdev-page-banners` category
- All others → `cdev-content-blocks` category
- Folders prefixed with `_` are hidden from the inserter

### Block folder structure
Each block folder contains:
- `block.json` — ACF block definition (name: `cdev/<block-name>`, renderTemplate, supports, example)
- `<block-name>.php` — render template
- `_block.scss` — styles (imported in `blocks/_blocks.scss`)

### Render template pattern
```php
<?php
// Get preview image (for editor inserter thumbnail)
if (display_preview_image()) {
    return;
}

// Get ACF fields
$field = get_field('field_name');
if (!$field) {
    $field = "Placeholder text";
}
?>

<div class="<?php get_block_options(); ?>" <?php render_block_anchor(); ?>>
    <?php echo esc_html($field); ?>
</div>
```

### Key helper functions (from `blocks/blocks.php`)
- `get_block_options($block_size_override)` — returns space-separated CSS classes from ACF block option fields (size, background, padding, margin, animation, etc.)
- `render_block_anchor()` — outputs `id="..."` attribute if an anchor is set
- `display_preview_image()` — renders editor inserter preview thumbnail; returns `true` if preview mode

## Sass variables (from `sass/_variables.scss`)

> Values sourced from `sass/_variables.scss`.

### Colors
| Variable | Value | Description |
|---|---|---|
| `$primary-color` | `#464646` | DK Gray |
| `$secondary-color` | `#202020` | Blackish |
| `$color3` | `aqua` | Aqua accent |
| `$color4` | `#CCC` | LT gray (box stroke / light bg) |
| `$color5` | `#202020` | DK Gray (footer bg) |

### Typography
- Base font: `'Roboto'` (loaded via Google Fonts)
- Headings font: `'Libre Franklin'` — weight `700`
- Base font color: `#333`
- Headings font color: `#444`
- Fluid typography using CSS custom properties (`--step--2` through `--step-6`)

### Font Awesome
- Version 6.5.2 (local, in `includes/fontawesome-6.5.2/`)
- Variables: `$font-stack-awesome-free`, `$font-stack-awesome-brands`
- Mixins: `@mixin awesome-icon`, `@mixin awesome-brand`

### Sass helper functions
- `px-rem($px)` — converts px to rem
- `rem-px($rem)` — converts rem to px
- `fluid-clamp($min, $max)` — generates a `clamp()` value for fluid sizing (viewport 500px–1230px)

## Scripts & libraries
- **jQuery** — used throughout (no removal of jQuery, no vanilla JS rewrites unless asked)
- **Slick carousel** — `includes/slick/` — used by page-header, home-header, logo-slider, slideshow blocks
- **has-animation.js** — intersection observer animation trigger
- **core.js** — site-wide scripts

## WordPress configuration
- Block lock: users cannot unlock locked blocks (e.g., `page-header`)
- Page template dropdown hidden in editor
- Default new page content: `page-header` + `column-one` blocks
- Home page content: `home-header` + `home-elevator` blocks
- Allowed blocks: only `cdev/*` custom blocks + `core/block` (reusable blocks)
- Fullscreen editor mode disabled by default
